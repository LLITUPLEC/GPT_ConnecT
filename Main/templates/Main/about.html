Возможности

Авторизованный пользователь:
  • Регистрация и авторизация;
  • Создание КМО;
  • Создание, редактирование и удаление неисправностей КМО;
  • Добавление членов комиссии;
  • Утверждение КМО (только для председателей);
  • Устранение неисправностей;
  • Формирование акта КМО (Excel);
  • Генерация QR-кодов по стрелочным переводам и путям.
Администратор:
  • Все функции авторизованного пользователя;
  • Полный набор операций CRUD по всем таблицам;
  • Назначение прав, ролей и групп доступа;
  • Загрузка большинства справочников в автоматическом режиме из Excel-файлов (филиалы, станции, стрелочные переводы, пути, должности, неисправности и др.);
  • Назначение ответственных лиц по филиалам и службам;
  • Назначение председателей (признак в таблице «Работники» — «Является председателем»);
  • Назначение членов комиссии (логически связанных с председателями).

Приложение

Приложение полностью адаптировано под разные размеры экранов (включая мобильные устройства). Для удобства просмотра таблицы используются адаптивные решения. Также есть собственная административная панель и система пагинации.

Логика работы

Работа с системой начинается с процесса регистрации и авторизации. Только после успешной авторизации пользователи получают доступ к основным возможностям системы. Каждый пользователь привязывается к таблице «Работники», этот процесс выполняется администратором.

  • Каждый авторизованный пользователь может создавать КМО, однако данная возможность может быть ограничена для некоторых ролей.
  • Запрет на дублирование КМО: в одном периоде и филиале допускается создание только одной записи.
  • Удаление КМО разрешено только пользователям с определённой ролью.
  • Карточка КМО разделяется на вкладки по службам для упрощённого управления (например, «Служба СП», «Служба СЦБ», «Служба СПиМР»).
  • При добавлении неисправности ответственный определяется автоматически на основе данных создателя (должность, служба и назначенные ответственные лица из справочников).
  • Выбор филиала автоматически обновляет список доступных станций, аналогично для выбора станции и стрелочных переводов.
  • Каждая карточка КМО имеет статус, который выделяется цветом и текстом. Сразу после создания КМО её статус обозначается как «Оформляется» (синий цвет).
  • После завершения ввода неисправностей председатель подтверждает КМО, нажимая кнопку «Утверждение». Это действие предотвращает последующие изменения неисправностей в данной КМО.
  • Устранение неисправностей возможно только после утверждения КМО.
  • Неисправности, не устранённые в указанный срок, помечаются красным цветом, своевременно выполненные — зелёным.
  • QR-код генерируется один раз для каждого объекта и шифрует ссылку на все зарегистрированные неисправности данного объекта, а также ссылку на последнюю версию КМО. Если неисправностей не существует, выводится соответствующее сообщение.

Планируемые доработки

  • Настройка фильтров для табличных данных (2–3 дня);
  • Интеграция операций CRUD для справочников непосредственно в интерфейс приложения (3–4 дня);
  • Расширение функциональности личного кабинета пользователя (добавление аватарки, информация о профессии) (1 день);
  • Разработка нового раздела «Обращения» (2 дня);
  • Дополнительная стилистическая доработка интерфейса (по запросу) (~2 дня);
  • Реализация возможности назначения нарядов по неисправностям (в зависимости от технического задания, ~7 дней).
